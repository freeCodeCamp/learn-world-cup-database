# World Cup Database Tutorial

This repository contains the interactive Relational Database project for building a World Cup Database as part of the freeCodeCamp curriculum.

## How to Run the Course

### Recommended (Gitpod / freeCodeCamp)
The standard way to complete this course is by using the **"Start the Project"** button directly on [freeCodeCamp.org](https://www.freecodecamp.org/learn/relational-database/build-a-world-cup-database-project/build-a-world-cup-database). This automatically provisions the full environment via Gitpod and CodeRoad.

### Running Locally or Finding Course Files
If you are running the course locally or looking for dataset files (such as `games.csv`):

1. **Version Branches:** Active course files, dataset CSVs, and reset scripts are located in the version branch referenced inside `coderoad.yaml` (e.g., branch `v2.0.0`), rather than on the `main` branch.
2. **Accessing CSV Files:** Switch to the corresponding version branch or view `.freeCodeCamp/reset_files` on that branch to inspect or copy the source `.csv` dataset files.
3. **Local Setup:** Follow the [freeCodeCamp Relational Database Local Setup Instructions](https://forum.freecodecamp.org/t/how-to-run-the-relational-database-curriculum-in-vscode-locally/500200) for running CodeRoad in VS Code.
