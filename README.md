# Build a World Cup Database

Welcome to the World Cup Database project! In this course, you'll learn relational database design and SQL by building a database of World Cup tournament data.

## Project Overview

This project teaches you how to:
- Create and design relational databases
- Write SQL queries and commands
- Work with CSV data and database imports
- Build a functional database schema for a World Cup tournament

## Getting Started

### Recommended Method: Online Learning (No Installation Required)

The easiest way to complete this course is to use the freeCodeCamp learning platform:

1. Visit the course page: [Build a World Cup Database Project](https://www.freecodecamp.org/learn/relational-database/build-a-world-cup-database-project/build-a-world-cup-database)
2. Click the "Start the course" button
3. Follow the interactive lessons and complete the challenges

This method requires no setup on your machine and provides an integrated learning environment.

### Self-Hosted Setup

If you prefer to work locally on your own machine, follow these steps:

#### 1. Find the Version Branch

The repository has different versions for different course releases. Check the `coderoad.yaml` file to find the version branch:

```bash
grep "branch:" coderoad.yaml
```

Current version branch: `v2.0.0`

#### 2. Clone the Repository

Clone the specific version branch to your machine:

```bash
git clone --branch v2.0.0 https://github.com/freeCodeCamp/learn-world-cup-database.git
cd learn-world-cup-database
```

#### 3. Set Up Your Environment

After cloning, install the project dependencies:

```bash
npm install
```

The necessary files and scripts are pre-configured in the `.freeCodeCamp/` directory.

#### 4. Access Course Materials

All the course materials, including:
- CSV data files
- Database reset files
- Setup scripts

...are located in the `.freeCodeCamp/reset_files/` directory.

#### 5. Complete Local Setup

For detailed instructions on running the course locally on your machine, visit the freeCodeCamp contributor guide:

[How to Work on Coding Challenges](https://contribute.freecodecamp.org/how-to-work-on-coding-challenges/)
